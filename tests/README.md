# # Módulo de Pruebas (Tests)

Esta carpeta está reservada para alojar las pruebas unitarias, de integración y funcionales del **Sistema de Reservas de Espacios Universitarios**.

## Estado del Módulo

En la fase actual del proyecto se define la estructura base del repositorio para garantizar su mantenibilidad y evolución. La especificación, diseño e implementación de los casos de prueba automatizados se integrarán en las siguientes fases del curso[cite: 3].

## Estructura Prevista

* `/unit`: Pruebas unitarias para componentes del frontend y servicios del backend.

* `/integration`: Pruebas de integración para endpoints de la API y persistencia en MongoDB.
